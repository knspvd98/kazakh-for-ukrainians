# Внесок у проєкт

## Підготовка

```bash
npm ci
npm run dev
```

Використовуйте Node.js 20 або новішу версію.

## Вимоги до змін

- інтерфейс і пояснення залишаються українською;
- казахський текст використовується як навчальний матеріал;
- кожен новий приклад повинен мати український переклад;
- не додавайте неперевірені сервісні репліки до публічного контенту;
- не створюйте словникові записи для суфіксів, словоформ або готових фраз;
- вільний текст не повинен мати фейкової автоматичної перевірки;
- аудіо додається лише до повних казахських слів і реплік.

## Перевірка

Перед commit виконайте:

```bash
npm run check
```

Якщо додано новий казахський текст з кнопкою відтворення:

```bash
npm run audio:generate
npm run audio:check
```

## Pull request

Опишіть:

1. що змінено;
2. навіщо потрібна зміна;
3. які уроки або довідники вона зачіпає;
4. які команди перевірки виконані.
