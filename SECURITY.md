# Політика безпеки

## Повідомлення про проблему

Не публікуйте токени, паролі, адреси електронної пошти або інші секрети у відкритому issue. Для приватного повідомлення використовуйте контакт власника репозиторію через профіль GitHub.

## Секрети

- `.env` та `.env.*` ігноруються Git;
- `.env.example` містить лише назви опціональних змінних;
- frontend не повинен містити токени TTS-провайдерів;
- прогрес навчання зберігається локально в браузері.

## Підтримувана версія

Виправлення застосовуються до актуальної версії гілки `main`.
